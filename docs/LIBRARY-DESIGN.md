# 회의 라이브러리 화면 개선

2026-11-05. 다글로의 공개 가이드와 Meeting Recorder 실행 화면을 근거로 기존 SwiftUI 화면을 개선했다.

## 참고와 적용 범위

- [다글로 화면 구성 가이드](https://daglo.ai/d/ko/guide/getting-started/explore-daglo): 검색·필터의 통합 배치, 새 작업의 강조, 문서 목록의 정보 위계를 참고했다.
- [다글로 제품 소개](https://daglo.ai/d/ko/product): 화자·시각과 발언의 연결을 참고했다.
- 로그인한 다글로 서비스는 확인하지 않았다. 공식 가이드의 공개 스크린샷을 읽었으며, 웹 브라우저 연결은 사용할 수 없었다.
- 네이티브 Mac 탐색 구조와 기존 청록색은 유지했다. 새로운 AI 기능이나 문서 편집 기능은 이번 변경에 포함하지 않는다.

## 바뀐 화면

1. **목록과 검색**: 새 녹음을 주행동으로 강조하고 검색창 오른쪽에 범위 메뉴를 배치했다. 날짜는 한국어로 표시한다. 같은 회의의 검색 결과를 한 그룹에, 같은 문단의 일치를 한 카드에 모은다. 문단 안의 이전·다음 일치도 선택할 수 있다.
2. **근거 확인**: 문서 위 검색 막대에서 결과 순서·이전·다음·원음 재생을 제공한다. 발언 선택 시 동일한 12pt 여백을 유지하며, 배경과 표시선으로 강조한다. 원래 검색 hit의 문서 버전과 재생 시각을 그대로 사용한다.
3. **문서 조작**: 파일·폴더·경로 조작은 제목 오른쪽 메뉴에 모았다. 모델 선택과 요약 생성은 회의 요약 탭에 배치한다. 요약을 요청할 서비스와 대화록 전송 안내를 함께 표시한다.
4. **원음 재생**: 재생기를 별도의 표면으로 구분하고, 현재 문서의 실제 시간 구간이 있을 때 화자와 발언 시작 시각을 표시한다. 요약과 연결되지 않은 외부 편집 문서에 발언 시각을 추정하지 않는다.
5. **가독성**: 본문 기본 크기는 15pt, 보조 정보는 11~13pt로 정리했다. 일부 아이콘 조작 영역을 28~36pt로 확대하고, 호버 전환은 동작 줄이기 설정을 따른다. 강조 버튼은 라이트·다크 테마에 맞는 글자색을 사용한다.

## 보존한 동작

검색 그룹은 표시 방식에만 적용한다. 회의 ID·디렉터리·문서 종류·문서 버전·블록 ID를 사용하며, 일치 구절을 이동하거나 재생할 때 원래 검색 결과를 전달한다. 외부 Markdown의 현재 내용, 해시 검사와 충돌 방지, 원음·원시 전사·요약 이력의 저장 규칙은 유지한다. 저장된 목록에 원시 segments 기반 미리보기를 새로 추가하지 않아 외부 편집 문서와 다른 내용을 표시하지 않도록 했다.

녹음·저장·취소·복구·노치 구현과 모델 설정은 변경하지 않았다. 신규 모델 설치나 외부 서비스 자동 호출도 추가하지 않았다. 앱 업데이트는 기존 Keychain 인증서를 재사용하는 `bash scripts/build-app.sh`로 수행했다.

## 검증

- `RecorderChecks`: 65/65 통과. 검색·외부 수정·원음 연결을 포함한 기존 회귀 검사.
- 실행 화면: 기존 기록 13개 열기, 같은 문단의 2개 일치가 한 카드로 묶이는지 확인, 두 번째 일치 이동·강조, 원음 재생 및 일시정지, 재생기 화자·시각 표시 확인.
- 검색 범위: 제목 범위로 변경했을 때 본문 단어가 결과 0곳으로 표시됨을 확인.
- 파일 메뉴: 회의 폴더·Markdown·파일 경로·요약 요청·삭제 메뉴의 접근 경로 확인. 삭제나 외부 요약 요청은 실행하지 않았다.
- 작은 창: 폭 820pt에서 문서 탭·빈 요약 상태·재생 조작이 보이는지 실제 화면 확인. 창 높이는 672pt였다.
- 테마 토큰 계산: 강조 버튼 글자/배경 대비는 라이트 5.47:1, 다크 7.44:1. 렌더링된 전체 UI의 대비 인증을 뜻하지 않는다.
- 실제 원본과 화면 캡처는 로컬 `.build/design-polish/`에 보관한다. 개인 기록이 포함되어 저장소에는 추가하지 않는다.

라이트 모드 실행 화면, VoiceOver, 긴 모델명을 선택한 상태, 실제 외부 요약 생성·취소, 변경 후 실제 녹음 권한은 이번 디자인 변경의 UI 검증에서 별도로 시험하지 않았다. 자동 회귀 검사와 화면에서 확인한 항목을 구분한다.

## 다음 연결 지점

긴 회의에서 재생 중 발언으로 따라가기와 현재 문서 기반 목록 미리보기를 후속으로 검토할 수 있다. 이번 변경은 검색과 읽기 흐름을 개선하며, 비파괴 편집·파일 가져오기·질문 답변·후속 작업 등 별도 백로그를 구현하지 않는다.
