# Meeting Recorder 성능 개선 측정 — 2026-11-04

녹음 후 **문장 다듬기**에 Metal GPU 자동 가속을 적용했습니다. M5·16GB에서 같은 한국어 시험 문단 6개를 각 방식으로 3회씩 처리했을 때 평균 시간이 **10.64초 → 4.82초(54.7% 감소, 2.21배 처리 속도)**로 줄었습니다.

## 변경 사항

- CPU 4스레드 고정 실행에서 `llama.cpp`의 자동 GPU 선택과 메모리 맞춤 설정으로 변경했습니다. CPU 보조 스레드는 4개로 유지합니다.
- GPU 경로 초기화 실패 시 먼저 해당 프로세스를 정리한 다음 기존 CPU 방식으로 한 번 재시도합니다. 취소하면 재시도하지 않습니다.
- 모델은 작업 중에만 유지하고 종료 시 해제합니다. 원문 저장 방식과 문단별 중단·이어하기는 유지합니다.
- 실제 앱 실행 경로에서 시간과 토큰 수를 출력하는 선택적 성능 측정 명령을 추가했습니다.

## 반복 측정 결과

| 지표 | 기존 CPU | 개선 후 GPU 자동 선택 |
| --- | ---: | ---: |
| 문단 처리 시간 평균 | 10.64 초 | 4.82 초 |
| 문단 처리 시간 중앙값 | 8.59 초 | 4.06 초 |
| 18회 요청 처리 시간 합계 | 191.52 초 | 86.72 초 |

| 6문단당 CPU 누적 시간 평균 | 215.89 CPU초 | 12.55 CPU초 |
| 측정된 프로세스 최대 RSS | 2.99 GiB | 3.29 GiB |

CPU 누적 시간은 여러 코어가 실행한 시간의 합입니다. 94.2% 감소했지만 GPU 소비 전력까지 측정한 값이 아니므로 배터리 절감률로 해석하면 안 됩니다. RSS는 200ms 간격으로 관찰한 서버 프로세스의 상주 메모리이며 전체 시스템·GPU 통합 메모리 사용량은 아닙니다. 약 0.30GiB(9.9%) 증가했습니다.

## 결과 보존과 실제 앱 확인

- 두 방식 모두 18/18 요청이 정상 종료됐고 출력 잘림이 없었습니다.
- 숫자·이름·기술용어·부정·불확실성 등 지정한 44개 문자열의 포함 여부를 3회 확인했습니다. 각 방식 132/132회 보존됐습니다. 이는 한정된 표현 보존 검사이며 정확도 100%를 뜻하지 않습니다.
- CPU/GPU 결과를 직접 비교했습니다. 6개 중 3개 문단은 동일했고, 나머지 3개에는 띄어쓰기·쉼표·어미 차이가 있었습니다. 각 방식의 결과는 3회 반복에서 동일했습니다.
- 서명된 실제 앱에서도 같은 6문단을 각 방식으로 추가 처리했습니다. 평균 CPU **10.09초**, 자동 가속 **4.60초**였고 표현 보존 검사도 통과했습니다. 이 추가 검증은 위 반복 측정 통계에 합치지 않았습니다.
- 기존 회귀 검사 **44/44** 통과. GPU 실패 후 CPU 재시도와 이전 프로세스 종료, 양쪽 실패, 시작 중 취소, 출력 잘림의 별도 검사 **4종** 통과.

## 조건과 한계

- Apple M5, 메모리 16GiB, macOS 26.5.1.
- Ollama 번들 llama-server `0.4.1-dev`, build 1, commit `391fac164`.
- `qwen3.5:4b`, 모델 SHA-256 `81fb60c7daa80fc1123380b98970b320ae233409f0f71a72ed7b9b0d62f40490`.
- 기존 기준 소스: `b517ff7`. 모델·지시문·입력·temperature 0·출력 제한 1024토큰·문맥 4096·동시 요청 1을 고정했습니다.
- 실행 순서는 CPU→GPU / GPU→CPU / CPU→GPU이며 각 배치마다 프로세스를 재시작했습니다. 최초 요청도 포함했고 별도 워밍업 요청은 넣지 않았습니다. 엔진 자체의 시작 워밍업과 운영체제 파일 캐시는 사용됩니다.
- 전용 시험 장비가 아닌 사용 중인 Mac의 측정입니다. 6문단 배치 시간 범위는 CPU 53.16~71.00초, GPU 27.95~29.50초였으며 다른 앱·온도·전원 상태에 따라 달라질 수 있습니다.
- 이번 수치는 **텍스트 문장 다듬기** 기준입니다. 실시간 음성인식 지연·CER/WER·전체 회의 정확도·배터리 사용량은 이번 실험에서 측정하지 않았습니다.
