# 미팅 레코더 팬 소리 억제 비교

2026년 11월 4일 · Apple M5 · 16GiB · macOS 26.5.1 · Whisper large-v3 (Metal)

**두 정확도 세트와 두 번의 지연 측정 모두 채택 조건을 충족했습니다. 레코더의 마이크 전사 설정에서 팬 소음 억제를 선택할 수 있도록 구현했습니다.** 팬 소리를 섞은 한국어 낭독 56문장에서 문자 오류율(CER)은 끄면 **5.62%**, 켜면 **5.51%**였습니다. 켰을 때의 전사 확정 시간은 1차 중앙값 2.32초, 2차 중앙값 2.31초였습니다.

## 설치본 검증

첫 배포 후보는 확정 중앙값 2.482초로 2.46초를 넘겨 설치를 보류했습니다. 다음 후보에서는 이미 준비된 억제 모델을 재사용하고, 새 녹음마다 음성 처리 상태만 초기화합니다. 오디오 조각마다 호출되던 중간 비동기 함수 한 단계도 줄였습니다. 모델, 억제 강도, 음성 데이터 및 말끝 감지 설정은 두 후보에 동일합니다.

정식 빌드가 사용하는 마이크 전사 모듈로 같은 16개 입력을 한 차례 더 재생했습니다. 억제를 켰을 때 확정 중앙값은 **2.30초**, P95는 **3.07초**였습니다. 16개 모두 확정됐고, 4개가 2.46초를 넘겼습니다. 이 8개 원문을 두 세기로 재생했을 때 CER은 142/784자(18.11%)였습니다. 별도 6개 입력(팬 혼합 3개, 원음 1개, 팬 단독 2개)의 정규화된 확정 텍스트가 실험용 실행 파일의 같은 조건과 모두 일치했습니다.

레코더 검사 49개와 기존 서명 호환성 검사를 통과했습니다. **설정 및 연결 → 전사 → 마이크 팬 소음 억제**에서 끄고 켤 수 있습니다. 검증한 Whisper large-v3 (Metal) 모델의 마이크 전사에 적용하며 원본 오디오는 보존합니다. 새 설치의 기본값은 끔입니다.

사전에 표시한 고유명사와 숫자의 허용 표기가 전사에 등장하는지 셌습니다. 숫자에는 값과 단위를 함께 요구한 항목이 있습니다. 팬이 큰 조건의 한 문장에서 끔은 정답인 ‘6천 명’을 맞혔고 켬은 ‘2000명’으로 인식했습니다. 동일 항목을 두 팬 세기에서 각각 확인했습니다. 팬만 재생한 대조군은 녹음 2종 × 음량 2단계 × 길이 3종(5·8·12초)입니다.

## 적용 판단과 실험 설계

| 사전에 정한 적용 조건 | 결과 |
|---|---|
| 32문장에서 두 팬 세기를 합친 CER이 감소 | 충족 |
| 별도 24문장에서 두 팬 세기를 합친 CER이 감소 | 충족 |
| 실시간 1차 중앙값 2.46초 이내 및 16개 모두 확정 | 충족 |
| 실시간 2차 중앙값 2.46초 이내 및 16개 모두 확정 | 충족 |

- **입력**. 공개 FLEURS 한국어 낭독에 실물 팬 A 또는 B의 안정 구간을 반복해 섞었습니다. 음성 중 에너지가 있는 20ms 구간만 골라 세기를 맞췄습니다. +5dB는 목소리가 팬보다 5dB 커서 더 시끄러운 조건입니다. 켬과 끔에 동일한 WAV를 주었고 팬은 원본 파일 끝에서 4초 더 돌았습니다. 저장된 파일을 다시 읽어 목표 신호 대 잡음비와의 차이가 모두 0.001dB 미만이고 파형이 잘리지 않았음을 확인했습니다.
- **필터 선택**. 16ms씩 처리하는 로컬 LocalVQE v1.3(CPU)을 사용했습니다. 개발 12문장의 오류는 끔 51/582, 원신호와 억제 신호를 절반씩 혼합한 모드 52/582, 완전 억제 69/582였습니다. 두 억제 강도 중 오류가 적었던 50% 혼합을 본 평가 전에 고정했습니다. 필터는 팬이 섞인 신호만 받았고 원음이나 팬 단독 녹음은 참조로 제공하지 않았습니다. 가중치는 [(FluidInference) LocalVQE](https://huggingface.co/FluidInference/localvqe-coreml/tree/4205430781c240397073d6f7bf676fb4c732fc12)에서 가져왔습니다.
- **레코더**. 기준 버전의 마이크 전사 경로 앞, 말소리 감지 전에 필터를 넣은 별도 실행 파일을 사용했습니다. 0.6초 말끝 대기, Silero 말소리 감지, Whisper large-v3 FP16, 미리보기와 확정 처리는 동일합니다. 56문장 CER은 입력 조각 처리가 끝날 때마다 다음 조각을 공급했고, 지연과 위의 별도 8문장 CER은 20ms 단위 실제 속도 재생에서 구했습니다. [기준 커밋](https://github.com/minnong511/meeting-auto-recoder/tree/34f3928cd2f196770c718a027897639e5c906469)
- **채점**. NFC 정규화, 영문 소문자 변환 뒤 공백·문장부호·기호를 제외했습니다. 삽입·삭제·치환 수의 합을 정답 글자 수로 나눴습니다. 한글 수사와 숫자 표기를 임의로 같게 처리하지 않았습니다. 본 평가, 별도 검증, 개발 세트 사이에 겹치는 문장 ID는 없습니다.
- **해석 범위**. 한 대의 Mac에서 측정한 두 종류의 일정한 팬 소리와 공개 낭독 결과입니다. 실제 회의실 마이크, 겹쳐 말하는 화자, 다른 잡음이나 다른 억제 모델의 결과는 측정하지 않았습니다.
