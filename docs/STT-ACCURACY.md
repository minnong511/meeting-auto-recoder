# Meeting Recorder 한국어 실시간 음성 인식 비교

2026-11-04 · Apple M5 / 통합 메모리 16 GiB / macOS 26.5.1 · 한 번에 한 모델, 한 입력으로 측정

**선택: Whisper large-v3 (947MB 변환판) + Silero 말소리 감지 + 확정 우선.** 한국어를 고정하고, 마이크와 회의 앱 소리의 말소리 판정 상태는 따로 유지합니다. 발화 앞 0.3초를 보존하고 약 0.6초간 말소리가 없으면 해당 구간의 확정 전사를 요청합니다. 무음이나 밀린 구간의 중간 자막은 건너뛰고 확정 요청을 먼저 처리합니다. 긴 발화는 단어 시각으로 겹치는 부분을 한 번만 저장합니다. 기존 모델 선택은 유지됩니다.

## 방식 선택에 사용한 32개 음성

서로 다른 문장 32개(428.94초, 정답 1,688자)와 말이 없는 12개 파일(100초)을 사용했습니다. CER는 낮을수록 좋고, 이름·숫자는 미리 표시한 정답 중 맞힌 개수입니다. 마지막 두 열은 같은 8개 음성을 실시간 재생한 별도 측정입니다.

| 모델 및 발화 구간 판정 | CER (오류 글자) | 고유명사 | 숫자 | 무발화 가짜 문장/파일 수 | 확정 중앙값 | 확정 P95 |
|---|---:|---:|---:|---:|---:|---:|
| Whisper Turbo 626MB · 음량 기준 (기존) | 8.95% (151) | 25/33 | 16/19 | 0/12 | 2.46초 | 5.18초 |
| Whisper Turbo 626MB · 말소리 감지 | 9.18% (155) | 26/33 | 16/19 | 0/12 | 2.12초 | 3.08초 |
| Whisper Turbo FP16 · 말소리 감지 | 9.42% (159) | 25/33 | 16/19 | 0/12 | 1.85초 | 2.41초 |
| Qwen3-ASR 1.7B 4bit · 말소리 감지 | 10.43% (176) | 26/33 | 16/19 | 0/12 | 1.97초 | 2.32초 |
| Whisper large-v3 947MB · 말소리 감지 (초기) | 8.18% (138) | 27/33 | 16/19 | 0/12 | 3.72초 | 7.05초 |
| Whisper large-v3 947MB · 말소리 감지 + 확정 우선 (적용) | 8.18% (138) | 27/33 | 16/19 | 0/12 | 3.72초 | 6.44초 |

기존 대비 선택 모델은 문자 오류가 151개에서 138개로 줄었습니다(0.77%p). 고유명사에는 사람뿐 아니라 지명·기관 등이 포함됩니다. 같은 음성에서 기존 방식의 ‘IT’는 새 방식에서 정답 ‘아이티’로 바뀌었지만, ‘고마’는 기존 방식만 맞혔습니다. 숫자 19개 중 16개를 양쪽 모두 맞혔습니다. 75.6cm, 62.2cm, 50mi는 양쪽 모두 사전 정의한 정답 표기가 나오지 않았습니다.

처음 비교한 다섯 조합 중 큰 Whisper의 전체 문자 오류율이 가장 낮아 모델을 고정했습니다. 확정 우선 변경 전후의 지연 중앙값은 3.72초 → 3.72초, P95는 7.05초 → 6.44초입니다. 위 표의 맨 마지막 줄이 실제 적용한 설정입니다.

디지털 무음 3개와 말 없는 합성 잡음 9개에서 다섯 방식 모두 가짜 확정 문장은 0개였습니다. 다만 전사 모델로 넘어간 미리보기·확정 요청은 기존 27회, 선택한 방식 0회였습니다. 전체 44개를 빠르게 공급해 끝낸 시간은 각각 132.6초와 274.3초로, 말소리가 있을 때 큰 모델은 더 많은 처리가 필요합니다. 이 값은 실제 발화 후 확정 지연과 다릅니다.

## 선택 후 독립 검증: 새 문장 24개

이 24개는 모델과 설정을 고정한 뒤에만 비교했습니다. 이번 앞선 음성, 과거 비교에 썼던 음성 어느 쪽과도 문장 ID가 겹치지 않습니다. 공개 낭독 약 5분 13초입니다.

| 방식 | CER (오류/정답 글자) | 고유명사 | 숫자 |
|---|---:|---:|---:|
| 기존 | 2.21% (25/1133) | 15/16 | 6/8 |
| 선택한 방식 | 1.50% (17/1133) | 16/16 | 6/8 |

독립 24개에서 CER는 2.21%에서 1.50%로 낮아졌습니다. 인식기나 정답은 이 결과를 보고 다시 조정하지 않았습니다.

문장 단위 대응 부트스트랩(10,000회)으로 구한 ‘기존 CER − 새 CER’의 95% 구간은 선택 32개에서 -0.05 ~ +1.84%p, 독립 24개에서 +0.00 ~ +1.56%p였습니다. 표본이 작아 이 차이를 모든 한국어 회의에 보장할 수 없습니다.

## 시간과 정확도를 해석할 때

- **확정 지연**은 모델 준비를 끝낸 뒤 20ms 단위로 실제 속도로 입력하며, 마지막 비어 있지 않은 확정 문장이 앱 처리기로 전달된 시각에서 마지막 말소리의 추정 끝을 뺀 값입니다. 기존 중앙값/P95는 2.46/5.18초, 선택 방식은 3.72/6.44초입니다. 파일 끝을 대신 기준으로 쓰면 중앙값은 각각 0.68초와 1.63초입니다. 파일 끝에는 침묵이 있으므로 두 기준을 혼용하지 않았습니다. 측정 8개 중 확정 누락은 기존 0개, 선택 방식 0개입니다. P95는 8개 값의 선형 보간으로, 장시간 회의의 꼬리 지연 추정으로 쓰기에는 작습니다.
- **종료 기준**은 모델 출력이나 해당 VAD에 맞추지 않고 사전에 음성 마지막 5초의 스펙트로그램에서 판독했습니다. 고립된 클릭과 일정한 배경음은 제외했습니다. 사람이 단어 단위로 정렬한 정답은 아닙니다. 장치 입력·화면 표시·디스크 저장 지연, 다운로드와 첫 모델 준비 시간은 제외했습니다.
- **CER**는 정답 글자에 대한 삽입·삭제·치환의 합입니다. NFC 정규화 후 공백·문장부호·기호·대소문자만 통일했습니다. **숫자 적중**에서는 단위가 같은 사전 허용 표기(예: 33만 명, 330000명)를 인정합니다. 문장 마침표 뒤에 나오는 33만 명을 소수점의 일부로 잘못 처리하던 채점 오류를 고쳐 모든 모델을 동일하게 재채점했습니다. 정답 목록과 모델은 바꾸지 않았습니다.
- 12개 별도 음성으로 구간 설정을 결정했습니다. 비교 32개의 9개 문장 ID는 과거 확장 실험에도 있었으므로 완전 미사용 표본으로 보지 않습니다. 마지막 24개는 과거 확장 자료에서도 제외했습니다. 원 데이터 정답에는 일부 영문 병기와 특수 표기가 있습니다. 이를 임의로 빼거나 모델에 알려 주지 않았습니다.
- 공개 낭독, 한 장치, 1회씩의 재생입니다. 여러 사람이 겹쳐 말하거나 마이크가 먼 실제 사용자 회의에 대한 CER, 특화 용어·팀원 이름의 적중률은 측정하지 않았습니다.

## 재현과 출처

[재현 명령·고정된 음성 목록·채점 코드](https://github.com/minnong511/meeting-auto-recoder/tree/main/experiments/accuracy). 입력 음성은 [Google FLEURS 한국어](https://huggingface.co/datasets/google/fleurs/tree/70bb2e84b976b7e960aa89f1c648e09c59f894dd/data/ko_kr), CC BY 4.0입니다. 회의 녹음은 이 비교에 쓰지 않았습니다.

앱은 [OpenAI Whisper](https://github.com/openai/whisper), [Argmax Core ML 변환 모델](https://huggingface.co/argmaxinc/whisperkit-coreml), [FluidInference의 Silero Core ML](https://huggingface.co/FluidInference/silero-vad-coreml)을 Mac에서 실행합니다. Whisper 세 후보의 대용량 가중치는 고정 리비전의 SHA-256과 대조했습니다. [Qwen3-ASR](https://huggingface.co/Qwen/Qwen3-ASR-1.7B)는 [MLX 4bit 변환판](https://huggingface.co/mlx-community/Qwen3-ASR-1.7B-4bit)으로 비교했으며 앱에는 포함하지 않았습니다.

앱 회귀 검사 47개가 모두 통과했습니다. 공개 음성을 시스템·마이크 두 입력에 공급한 추가 검사에서도 첫 마이크 입력(잡음만 있음)은 비어 있었고, 두 입력에 동시에 보낸 발화는 각각 확정됐습니다.
