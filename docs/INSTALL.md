# Meeting Recorder 설치 방법

**0.8.1** (빌드 19)은 2026년 11월 4일 공개한 Apple Silicon용 정식 배포본입니다. [릴리스 노트](https://github.com/minnong511/meeting-auto-recoder/releases/tag/v0.8.1) · [ZIP 다운로드](https://github.com/minnong511/meeting-auto-recoder/releases/download/v0.8.1/Meeting-Recorder-0.8.1-macOS-arm64.zip)

## 준비 사항

- Apple Silicon Mac(M1 이후)
- macOS 26 이상
- 첫 STT 모델 다운로드를 위한 인터넷 연결
- 0.8.1에서는 메모리 16GB 이상 Mac의 기본 GPU 모델에 약 3.10GB, 그보다 작은 Mac의 기본 Core ML 모델에 약 948MB가 필요합니다. 토크나이저·캐시·녹음 파일을 위한 공간이 추가로 필요합니다.

이 배포본에는 앱과 MCP 서버가 들어 있습니다. Xcode, Python, Qwen 또는 Cohere 모델 설치는 필요하지 않습니다. Intel Mac용 실행 파일은 포함하지 않습니다.

**앱을 받는 사용자는 인증서나 개인 키를 만들거나 설치할 필요가 없습니다.** 서명된 배포본을 그대로 사용하세요. 키체인과 `signing.json`은 소스에서 앱을 빌드하는 개발자의 서명 설정입니다. macOS의 앱 실행 승인과 녹음 권한 허용은 각 사용자 Mac에서 필요할 수 있습니다.

## 터미널 명령으로 설치

다음 한 줄로 앱과 MCP 서버를 설치하고 Whisper 음성인식 모델까지 준비할 수 있습니다.

```sh
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/minnong511/meeting-auto-recoder/main/scripts/install.sh | /bin/bash
```

1. 고정된 배포 커밋의 0.8.1 ZIP을 내려받고 설치 스크립트에 기록된 SHA-256과 비교합니다.
2. 앱과 MCP 서버의 서명을 검사한 뒤 설치합니다. 기존 `/Applications` 또는 `~/Applications`의 앱을 먼저 찾습니다. 두 위치에 모두 있으면 설치 폴더를 직접 선택해야 합니다. 새 설치는 쓰기 가능한 `/Applications`를 우선 사용하고, 권한이 없으면 `~/Applications`를 사용합니다.
3. Mac 메모리에 맞는 권장 Whisper 모델과 필요한 음성 인식 파일을 준비합니다. 설치된 모델 캐시가 있으면 재사용합니다. 네트워크 속도에 따라 첫 준비에 수 분이 걸릴 수 있습니다.
4. 앱을 엽니다. 저장 폴더 선택과 macOS의 실행 승인·시스템 오디오·마이크 권한 허용은 직접 진행합니다. 회의 요약을 사용하려면 아래 ‘LLM에서 요약하기’를 따릅니다.

`sudo` 없이 실행하세요. 관리자 암호, Xcode, Python 설치는 필요하지 않습니다. 모델 준비 실패 시 앱은 설치된 상태로 남고 명령은 종료 코드 2를 반환합니다. 인터넷 연결과 실행 승인을 확인한 뒤 다시 실행하거나 첫 녹음 때 모델 준비를 재시도하세요.

앱만 설치하고 모델은 첫 녹음 때 준비하려면:

```sh
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/minnong511/meeting-auto-recoder/main/scripts/install.sh | /bin/bash -s -- --skip-model
```

설치 위치를 직접 지정하려면:

```sh
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/minnong511/meeting-auto-recoder/main/scripts/install.sh | /bin/bash -s -- --install-dir "$HOME/Applications"
```

설치 후 앱 실행을 생략하려면 `--no-open`을 추가합니다. 스크립트를 먼저 확인한 뒤 실행하거나 로컬 ZIP을 사용하려면 저장소에서 다음과 같이 실행할 수도 있습니다.

```sh
bash scripts/install.sh --help
bash scripts/install.sh --archive releases/Meeting-Recorder-0.8.1-macOS-arm64.zip
```

녹음 후 로컬 모델로 문장을 다듬으려면 `--with-ollama`를 추가해 Ollama를 설치할 수 있습니다. 모델까지 내려받으려면 `--ollama-model 모델이름`도 함께 지정하세요.

이 명령은 현재 사용자 계정에 설치합니다. 녹음 파일과 기존 설정은 유지하며, 실행 중인 앱의 교체와 다른 서명의 앱으로 업데이트하는 작업은 거부합니다. 이전 앱은 설치 폴더 안의 숨김 폴더 `.meeting-recorder-backups/`에 보관해 실행 중인 MCP 연결의 파일을 유지합니다. 이전 버전에 연결된 LLM 앱을 모두 종료한 뒤 더 이상 필요 없는 백업을 지울 수 있습니다. 개발용 체크아웃의 앱 업데이트는 [개발자 가이드](https://github.com/minnong511/meeting-auto-recoder/blob/v0.8.1/docs/BUILDING.md)의 `scripts/build-app.sh`를 사용하세요.

## 1. ZIP으로 직접 설치

1. ZIP을 압축 해제합니다.
2. `Meeting Recorder.app`을 Finder의 **응용 프로그램** 폴더로 옮깁니다.
3. `/Applications/Meeting Recorder.app`을 실행합니다. 이후 같은 위치에서 실행하는 것을 권장합니다.

### 실행이 차단되는 경우

현재 배포본은 **로컬 개발 인증서로 서명했으며 Apple 공증을 받지 않았습니다.**

출처와 파일 무결성을 확인한 배포본에 한해 다음 절차를 사용할 수 있습니다.

1. 앱을 한 번 실행해 macOS의 차단 안내를 확인합니다.
2. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
3. 보안 영역에서 이 앱에 대한 **확인 없이 열기(Open Anyway)**가 표시되면 선택하고 안내에 따라 승인합니다.

회사나 학교의 관리 정책에서는 이 선택지가 없거나 실행이 제한될 수 있습니다. 이 경우 관리자에게 문의하거나 공증 배포본을 사용해야 합니다. 시스템 전체의 보안 설정을 끄거나 앱을 다시 서명할 필요는 없습니다.

[Apple 공식 실행 안내](https://support.apple.com/en-gb/102445)

## 2. 첫 녹음 준비

1. 파일을 보관할 폴더를 선택합니다. 앱 내부가 아닌 문서 폴더 등 별도 위치를 권장합니다.
2. `새 녹음`을 누르고 Zoom, Teams 등의 녹음 대상을 선택합니다.
3. `내 마이크`를 켜면 내 목소리도 포함합니다. 꺼두면 선택 앱의 소리만 기록합니다.
4. **설정 및 연결 → 전사 → 전사 모델**에서 사용할 모델을 선택합니다. 기본값은 메모리 16GB 이상에서 Whisper large-v3 (Metal), 16GB 미만에서 Whisper large-v3 (Core ML)입니다. 직접 선택한 모델은 다음 녹음에도 사용합니다.
5. `녹음 시작`을 누릅니다. 모델의 크기, 속도와 인식 품질은 다르며 작은 모델은 한국어 전사에 오류가 더 생길 수 있습니다. 중요한 내용은 원본 녹음으로 확인하세요.
6. macOS가 요청하는 시스템 오디오 권한을 허용합니다. 마이크를 켠 경우에는 마이크 권한도 필요합니다.
7. 권한을 바꾼 뒤 필요하면 앱을 종료하고 다시 엽니다.

전사 모델은 녹음 시작 전에 선택합니다. 녹음 중에는 바꿀 수 없으며, 다른 모델을 선택해도 이전 녹음이나 대화록을 다시 처리하지 않습니다. 기존 모델 파일도 자동으로 삭제하지 않습니다. 녹음 후 대화록의 **문장 다듬기용 LLM**은 별도의 설정입니다.

앱이 실행되는 동안 화면 상단에 녹음 상태와 경과 시간이 표시됩니다. 표시에 마우스를 올리거나 왼쪽을 클릭하면 큰 경과 시간과 실제 입력 음량 바가 펼쳐집니다. 바는 마이크와 녹음 대상 소리의 음량 변화를 표시하며 주파수 분석값은 아닙니다. 녹음은 앱에서 시작하고, 녹음 중에는 상단의 정지 버튼으로 종료할 수 있습니다. **설정 및 연결 → 일반 → 노치에 녹음 상태 표시**에서 표시를 끌 수 있습니다. 데스크톱이나 전체 화면 앱을 전환해도 같은 화면 상단 위치를 유지하며, 노치가 없는 화면에서도 상단에 표시됩니다.

**설정 및 연결 → 일반 → 녹음에서 알림음 제외**는 기본으로 켜져 있습니다. 전체 시스템 녹음에서 macOS 알림 서비스, Slack, 카카오톡 소리를 제외합니다. 메신저 통화를 녹음하려면 그 앱을 직접 선택하세요.

권한은 **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음 / 마이크**에서 확인할 수 있습니다. 앱은 화면 영상을 파일로 저장하지 않습니다.

브라우저를 녹음 대상으로 선택하면 같은 브라우저의 다른 탭 소리도 포함됩니다. 상대방 소리가 실제로 재생되는지 확인하고, 필요하면 **설정 및 연결 → 전사 → 15초 테스트**를 사용하세요.

## 3. 대화록 확인

- 녹음 중 확정된 문장은 바로 저장됩니다. 종료 후 전체 녹음을 다른 모델로 다시 인식하지 않습니다.
- 기록을 열면 녹음 준비 카드가 접힙니다. `녹음 준비 펼치기`로 다시 열 수 있습니다.
- 문단 옆 시각을 누르면 해당 음성이 재생됩니다. 재생 바에 커서를 올려 파형과 시각을 보고 클릭하거나 드래그해 이동하세요. 하단에서 음량과 0.5–2배속을 선택할 수 있습니다.
- 기존 녹음의 오인식과 화자 미확정 표시는 자동 교정되지 않습니다. 문단의 시각으로 원본을 확인하세요.

회의 폴더에는 `audio.m4a`, `transcript.md`, 숨김 메타데이터 `.meeting.json`이 저장됩니다. 요약이 만들어지면 `summary.md`도 생깁니다. 파일을 옮길 때는 회의 폴더 전체를 함께 옮겨야 합니다.

## 4. LLM에서 요약하기 — 선택 사항

1. 사용할 Codex 또는 Claude Code 실행기를 설치하고 본인 계정에 로그인합니다.
2. **설정 및 연결 → 연결 → 자동 요약**에서 에이전트를 선택합니다. **요약 프롬프트**에 원하는 형식이나 문체를 입력하면 다음 요청부터 적용됩니다.
3. 저장을 마친 회의에서 **Codex로 요약** 또는 **Claude Code로 요약**을 누릅니다. 해당 회의의 대화록이 선택한 서비스로 전달되고 결과가 **회의 요약** 탭에 저장됩니다.

다른 MCP 클라이언트에서는 **설정 및 연결 → 연결 → MCP 연결 설정 복사**로 서버를 등록하고 회의의 **요약 요청 복사**를 사용하세요. **연결 세부정보**에서 연결된 앱과 세션을 확인할 수 있습니다.

## 5. 업데이트와 삭제

업데이트 전 녹음을 마치고 앱을 종료한 뒤 새 앱으로 교체하세요. 같은 배포자의 동일한 서명과 설치 경로를 유지하는 것이 좋습니다. 서명 주체나 경로가 바뀌면 macOS가 녹음 권한을 다시 요청할 수 있습니다.

설치 프로그램이 서명 불일치를 알리면 기존 앱을 임의로 삭제하거나 다시 서명하지 말고 배포자에게 호환되는 업데이트를 요청하세요. 기존 앱과 녹음 파일은 유지됩니다.

공식 0.8.0에서 0.8.1로 업데이트하려면 녹음을 마치고 앱을 종료한 뒤 같은 설치 명령을 실행하세요. 설치 프로그램이 기존 앱과 새 앱의 서명을 양방향으로 검사하고 이전 앱을 백업합니다. 설치가 중단돼 잠금 오류가 남으면 실행 중인 설치가 없는지 먼저 확인하세요.

앱을 삭제해도 별도로 선택한 녹음 저장 폴더는 남습니다. 앱 안에서 회의를 삭제하면 관련 파일은 Finder 휴지통으로 이동하므로 복구할 수 있습니다.
