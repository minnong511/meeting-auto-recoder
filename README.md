# Meeting Recorder

## 설치 방법

현재 공개 버전은 **0.8.0**이며 Apple Silicon Mac과 macOS 26 이상이 필요합니다. 첫 음성인식 모델 준비에는 인터넷 연결, 약 627MB의 다운로드와 추가 캐시 공간이 필요합니다. 사용자에게 별도의 인증서나 개발자 계정은 필요하지 않습니다.

터미널에 아래 명령을 입력합니다. 앱과 MCP 서버를 설치하고 음성인식 모델을 준비한 뒤 앱을 실행합니다.

```sh
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/minnong511/meeting-auto-recoder/main/scripts/install.sh | /bin/bash
```

또는 [0.8.0 ZIP 배포본](releases/Meeting-Recorder-0.8.0-macOS-arm64.zip)을 내려받아 압축을 풀고 `Meeting Recorder.app`을 응용 프로그램 폴더로 옮깁니다. 업데이트할 때는 먼저 녹음을 마치고 앱을 종료하세요.

현재 배포본은 Apple 공증을 받지 않았습니다. macOS가 앱 실행을 차단하면, 신뢰하는 배포본인지 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 앱별 실행을 승인하세요. 처음 사용할 때 저장 폴더를 선택하고 시스템 오디오 권한을 허용합니다. 내 목소리도 녹음하려면 마이크 권한을 허용합니다. 자세한 내용과 설치 옵션은 [설치 안내](docs/INSTALL.md)를 참고하세요.

## 사용 방법

1. 앱에서 **새 녹음**을 누르고 녹음할 앱 또는 전체 시스템 소리를 선택합니다.
2. **내 마이크** 포함 여부를 선택한 뒤 **녹음 시작**을 누릅니다.
3. 회의가 끝나면 **녹음 종료**를 누르고 저장이 완료될 때까지 기다립니다.
4. 회의 기록에서 대화록을 확인합니다. 문단 옆 시간을 누르면 해당 위치의 녹음을 재생할 수 있습니다.

브라우저를 녹음 대상으로 선택하면 같은 브라우저의 다른 탭 소리도 포함됩니다. 음성 인식은 이 Mac에서 실행됩니다.

**문장 다듬기:** 녹음이 끝난 기록의 **다듬은 대화록**에서 실행합니다. 공개된 0.8.0에서는 Ollama 앱과 `qwen3.5:4b` 모델이 필요합니다. 원문과 녹음은 보존되며, 결과는 원문과 비교해 확인하세요.

**회의 요약:** **설정 및 연결 → MCP 연결 설정 복사**를 눌러 MCP를 지원하는 LLM 앱에 연결합니다. 회의 기록에서 **요약 요청 복사**를 누르고 연결한 LLM에 붙여 넣으면, 저장된 결과를 **회의 요약**에서 확인할 수 있습니다. 외부 LLM을 사용할 경우 해당 서비스의 데이터 처리 정책이 적용됩니다.

개발 중인 0.8.1에서는 설정에서 전사 모델과 문장 다듬기 모델을 선택할 수 있으며, 녹음 상태를 화면 상단에 표시할 수 있습니다. 이 기능은 현재 공개된 0.8.0에는 포함되지 않습니다.
