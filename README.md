# Meeting Recorder

선택한 앱의 소리와 마이크를 녹음하고 한국어 대화록을 실시간으로 저장하는 macOS 앱입니다. 녹음과 음성 인식은 Mac에서 처리하며, 녹음된 회의를 검색하고 대화록과 원본 음성을 함께 확인할 수 있습니다.

> **버전 안내:** 현재 공개 배포본과 아래 설치 명령은 **0.8.0**입니다. 이 저장소의 개발 중인 **0.8.1**에는 문장 다듬기, 모델 선택, 화면 상단 녹음 상태 표시 등 추가 기능이 있습니다. 0.8.1은 소스에서 별도로 빌드해야 합니다.

## 프로젝트 구성

```text
Sources/
  MeetingRecorder/       macOS 앱 화면, 녹음 제어, 로컬 문장 다듬기
  RecorderAudio/         오디오 캡처, 내보내기, 음성 인식 처리
  RecorderCore/          회의 기록, 대화록, 데이터 저장 및 공통 로직
  MeetingRecorderMCP/    LLM 연결용 MCP 서버
  RecorderChecks/        회귀 검사
Resources/               앱 설정, 글꼴 및 외부 구성 요소 저작권 고지
scripts/                 앱 빌드·설치·서명·배포 및 검사 도구
docs/                    설치 안내와 개발자 빌드 가이드
releases/                공개 배포 ZIP과 SHA-256 목록
experiments/accuracy/    한국어 실시간 전사 비교와 재현 도구
experiments/asr/         과거 음성 인식 실험
```

Swift 기반 macOS 앱이며 음성 인식에는 WhisperKit과 Whisper 모델을 사용합니다. 녹음 데이터, 빌드 결과물과 개인 서명 설정은 저장소에 포함하지 않습니다.

## 프로젝트 프로그램 설치방법

### 실행 환경

- Apple Silicon Mac, macOS 26 이상
- 첫 음성 인식 모델 다운로드를 위한 인터넷 연결
- 공개판 0.8.0의 기본 모델은 약 627MB, 소스 빌드에서는 메모리 16GB 이상 Mac의 권장 Whisper large-v3 Metal 모델이 약 3.10GB, 16GB 미만 Mac의 기본 Core ML 모델이 약 948MB입니다. 토크나이저·말소리 감지 모델·녹음 파일용 공간이 추가로 필요합니다.
- 처음 녹음할 때 시스템 오디오 권한, 마이크를 사용하는 경우 마이크 권한

### 공개 배포본 0.8.0 설치

터미널에서 다음 명령을 실행하면 앱과 MCP 서버를 설치하고 기본 음성 인식 모델을 준비한 뒤 앱을 엽니다.

```sh
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/minnong511/meeting-auto-recoder/main/scripts/install.sh | /bin/bash
```

또는 [0.8.0 ZIP 배포본](releases/Meeting-Recorder-0.8.0-macOS-arm64.zip)을 압축 해제하고 `Meeting Recorder.app`을 응용 프로그램 폴더로 옮길 수 있습니다. 설치 옵션과 자세한 절차는 [설치 안내](docs/INSTALL.md)를 참고하세요.

현재 배포본은 로컬 개발 인증서로 서명했으며 **Apple 공증을 받지 않았습니다.** macOS에서 실행을 차단하면 출처를 확인한 뒤 시스템 설정에서 앱별 실행 승인이 필요할 수 있습니다. 일반 사용자는 별도 개발자 계정이나 서명 키가 필요하지 않습니다.

### 개발판 0.8.1 빌드

개발판의 소스 빌드에는 Swift 6.2 도구 모음, Python 3, CMake 3.28 이상 또는 uv가 필요합니다. 저장소를 내려받은 뒤 [개발자 빌드 가이드](docs/BUILDING.md)의 서명 준비를 확인하고 실행하세요.

```sh
# 진행 중인 녹음을 마치고 앱을 종료한 뒤 실행합니다.
bash scripts/build-app.sh
open 'dist/Meeting Recorder.app'
```

기존 설치를 업데이트할 때는 기존 서명 인증서를 유지해야 합니다. 서명 키가 없는 경우에는 임의로 재서명하거나 새 키를 만들기 전에 개발자 가이드의 안내를 확인하세요.

## 프로젝트 프로그램 사용법

### 녹음 및 대화록 확인

1. 앱을 열고 녹음 파일을 보관할 폴더를 선택합니다.
2. **새 녹음**을 누르고 녹음할 앱 또는 전체 시스템 소리를 선택합니다. 0.8.0에서는 **새 회의**로 표시될 수 있습니다.
3. 내 목소리를 포함하려면 **내 마이크**를 켜고 **녹음 시작**을 누릅니다. 필요한 macOS 권한을 허용합니다.
4. 회의가 끝나면 **녹음 종료**를 누르고 저장이 완료될 때까지 기다립니다.
5. 회의 목록에서 기록을 선택합니다. 대화록 문단 옆 시간을 누르면 해당 지점의 음성을 재생할 수 있습니다.

브라우저를 녹음 대상으로 선택하면 같은 브라우저의 다른 탭 소리도 포함됩니다. 전사에는 오류가 있을 수 있으므로 중요한 발언은 원본 녹음과 비교하세요.

### 한국어 음성 인식 (소스 빌드)

메모리 16GB 이상 Mac에서는 **Whisper large-v3 (Metal) + 말소리 감지**로 전사합니다. 16GB 미만 Mac의 기본값은 저장 공간을 덜 쓰는 Core ML 버전입니다. 마이크와 회의 앱은 각자 발화의 끝을 판단하고 녹음과 전사는 Mac에서 처리합니다. **설정 및 연결 → 전사 → 전사 모델**에서 모델을 바꿀 수 있습니다. 기존에 직접 고른 모델은 업데이트 후에도 유지합니다. [자막 확정 지연과 정확도 비교](docs/STT-LATENCY.md) · [이전 정확도 개선 측정](docs/STT-ACCURACY.md).

팬이 계속 돌아가는 곳에서는 **설정 및 연결 → 전사 → 마이크 팬 소음 억제**를 켤 수 있습니다. Whisper large-v3 (Metal)로 마이크를 전사할 때 적용하며, 처음에 약 20MB를 내려받습니다. 회의 앱 소리와 저장하는 원본 오디오는 별도로 처리합니다. [한국어 팬 소음 비교](docs/STT-FAN-SUPPRESSION.md)

### 문장 다듬기 — 개발판 0.8.1

Ollama와 내려받은 로컬 모델을 준비한 뒤 **설정 및 연결 → 전사 → 문장 다듬기**에서 모델을 선택합니다. 녹음이 끝난 회의의 **다듬은 대화록**에서 실행하면 원문과 별도로 결과를 저장합니다. 기본 모델은 `qwen3.5:4b`이며 모델 설치 방법은 [개발자 가이드](docs/BUILDING.md)를 참고하세요. 다듬은 결과도 원문 및 음성과 비교해 확인하세요.

지원되는 Mac에서는 GPU를 자동 활용하며, 가속 초기화가 실패하면 CPU로 다시 시도합니다. 작업이 끝나면 모델을 해제합니다. [성능 측정 결과와 한계](docs/PERFORMANCE.md)를 확인할 수 있습니다.

### 회의 기록 복사와 파일 위치 — 개발판 0.8.1

각 탭의 **대화록 복사**, **정리본 복사**, **요약 복사**로 문서 전체를 복사합니다(⌘⇧C). 대화록은 직접 편집한 Markdown을 포함하고, 부분 정리본은 처리되지 않은 문단을 ‘원문’으로 표시합니다. 문단 옆 버튼으로 한 문단만 복사할 수도 있습니다. 제목 옆 **회의 폴더**는 Finder에서 해당 폴더를 열고 **경로 복사**는 선택한 파일의 절대 경로를 복사합니다.

### 회의 요약 — 선택 사항

1. **설정 및 연결 → 연결 → MCP 연결 설정 복사**를 눌러 설정을 복사합니다.
2. MCP를 지원하는 LLM 앱에 설정을 붙여 넣고 연결을 활성화합니다.
3. 회의 기록에서 요약 요청을 복사해 해당 LLM에 전달합니다.
4. LLM이 요약을 저장하면 앱의 **회의 요약**에서 확인합니다.

외부 LLM을 사용하면 전달한 대화록에 해당 서비스의 데이터 처리 정책이 적용됩니다.

## 버그 및 디버그

- **소리가 녹음되지 않을 때:** 녹음 대상을 확인하고 macOS의 시스템 오디오 및 마이크 권한을 확인합니다. 브라우저를 선택한 경우 소리가 실제로 재생되는지도 확인하세요.
- **모델 준비가 실패할 때:** 인터넷 연결과 저장 공간을 확인한 뒤 다시 시도합니다. 기본 모델 외에 토크나이저와 캐시 공간도 필요합니다.

- **업데이트가 거부될 때:** 녹음을 마치고 앱을 종료했는지 확인합니다. 서명 불일치가 표시되면 임의로 앱을 다시 서명하지 말고 [개발자 가이드](docs/BUILDING.md)를 확인하세요.
- **문장 다듬기가 실행되지 않을 때:** 개발판인지, Ollama와 선택한 로컬 모델이 준비되어 있는지 확인합니다.

개발자는 아래 명령으로 회귀 검사를 실행할 수 있습니다. 빌드·서명 및 추가 검사 절차는 [개발자 가이드](docs/BUILDING.md)에 있습니다.

```sh
bash scripts/build-app.sh --package-only
.build/release/RecorderChecks
```

문제를 제보할 때는 사용 중인 앱 버전, macOS 버전, 재현 순서와 오류 메시지를 함께 기록해 주세요. 대화록이나 녹음 파일은 개인정보와 회의 참여자의 동의를 확인한 뒤 공유하세요.

## FAQ

### Q. 녹음과 전사는 인터넷으로 전송되나요?
녹음과 음성 인식은 Mac에서 처리합니다. 첫 모델 다운로드에는 인터넷이 필요하며, 별도로 외부 LLM에 요약을 요청하면 전달한 대화록은 해당 서비스로 전송됩니다.

### Q. 인터넷 없이 사용할 수 있나요?
필요한 음성 인식 모델을 미리 준비한 뒤에는 로컬 녹음과 전사를 사용할 수 있습니다. 모델 다운로드나 외부 LLM 서비스 사용에는 연결이 필요합니다.

### Q. 설치 명령을 다시 실행하면 0.8.1이 설치되나요?
아니요. 현재 설치 명령은 0.8.0 배포본에 고정되어 있습니다. 0.8.1 기능을 사용하려면 개발판을 직접 빌드해야 합니다.

### Q. 다듬은 대화록이 원문을 바꾸나요?
개발판의 문장 다듬기 결과는 별도로 저장하며 원본 대화록과 녹음은 유지합니다. 모델의 결과는 원문과 대조해 확인하세요.

### Q. 앱을 삭제하면 회의 기록도 삭제되나요?
별도로 선택한 녹음 저장 폴더는 앱을 삭제해도 남습니다. 회의 파일을 옮길 때는 회의 폴더 전체를 함께 옮기세요.
