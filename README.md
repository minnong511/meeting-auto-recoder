# Meeting Recorder

선택한 회의 앱의 소리와 내 마이크를 녹음하고, 한국어 실시간 대화록을 저장하는 macOS 앱입니다.

## 배포본 설치

**현재 버전: 0.8.0 · Apple Silicon · macOS 26 이상**

터미널에 다음 한 줄을 붙여 넣으면 **배포본 다운로드 → SHA-256·서명 검사 → 앱과 MCP 서버 설치 → 음성인식 모델 준비 → 앱 실행**까지 진행합니다. 관리자 암호나 Xcode, Python은 필요하지 않습니다.

```sh
curl -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/minnong511/meeting-auto-recoder-/main/scripts/install.sh | /bin/bash
```

기존 `/Applications` 또는 `~/Applications`의 앱 위치를 유지합니다. 새 설치는 쓰기 가능한 `/Applications`를 우선 사용하고, 권한이 없으면 `~/Applications`를 사용합니다. 업데이트 전 녹음을 마치고 앱을 종료하세요. 첫 모델 준비에는 인터넷 연결과 약 627MB 및 추가 캐시 공간이 필요합니다.

**macOS의 앱 실행 승인, 저장 폴더 선택, 시스템 오디오·마이크 권한 허용은 직접 해야 합니다.** LLM 요약을 사용하려면 앱에서 MCP 연결 설정을 복사해 사용하는 LLM 앱에 붙여 넣으세요. 설치 위치 선택과 모델 준비 생략 옵션은 [설치 README](docs/INSTALL.md#터미널-명령으로-설치)에 있습니다.

직접 설치하려면:

1. [ZIP 배포본](releases/Meeting-Recorder-0.8.0-macOS-arm64.zip)을 내려받아 압축을 풉니다.
2. 안의 `Meeting Recorder.app`을 **응용 프로그램** 폴더로 옮깁니다.
3. 앱을 실행하고 녹음 파일을 보관할 폴더를 선택합니다.
4. 처음 녹음할 때 시스템 오디오 권한을 허용합니다. 내 목소리를 포함하려면 마이크 권한도 허용합니다.
5. 처음 한 번 Whisper 모델을 내려받습니다. 인터넷 연결과 약 627MB의 모델 저장 공간이 필요하며, 토크나이저와 추가 캐시 공간도 사용합니다.

**이 ZIP은 로컬 개발 인증서로 서명한 비공증 배포본입니다.** 다른 Mac에서 내려받아 실행하면 macOS가 차단할 수 있습니다. 신뢰하는 배포본인지 확인한 뒤 Apple이 안내하는 시스템 설정의 앱별 실행 승인 절차를 사용하세요. 상세한 단계는 [설치 README](docs/INSTALL.md)에 있습니다. 조직의 보안 정책에 따라 실행이 허용되지 않을 수 있습니다.

일반 사용자에게 별도 승인 없이 제공할 공개 배포본은 Developer ID 서명과 Apple 공증이 추가로 필요합니다. 현재 ZIP을 공증 완료본으로 안내하지 않습니다.

## 주요 기능

- 선택 앱 소리 또는 전체 시스템 소리 녹음, 마이크 포함 여부 선택
- Whisper large-v3-turbo를 이용한 로컬 실시간 STT와 즉시 저장
- 종료 시 마지막 미확정 구간과 M4A 저장만 마무리하는 방식
- 기록 검토 시 녹음 준비 카드 접기, 문단 시각을 눌러 해당 음성 재생
- 재생 위치 막대, 10초 앞뒤 이동, 문단 복사
- 지원되는 기록의 수동 화자 구분: 기존 단어에 화자만 표시
- MCP를 연결한 LLM에서 대화록 읽기 및 요약 저장
- 회의 앱 감지 알림, 회의 기록 검색, 휴지통을 이용한 삭제·복구

음성 인식은 이 Mac에서 실행합니다. LLM 요약은 사용자가 연결한 서비스에 요청하는 별도 동작이며 해당 서비스의 데이터 처리 정책을 따릅니다. Qwen/Cohere Python 환경이나 실험 모델은 앱 실행에 필요하지 않습니다.

## 사용 방법

`새 회의` → 녹음할 앱 선택 → 마이크 포함 여부 확인 → `녹음 시작` → `녹음 종료` 순서로 사용합니다. 브라우저를 녹음 대상으로 고르면 같은 브라우저의 다른 탭 소리도 포함됩니다.

문단 옆 시각은 저장된 발언의 실제 시작 시간을 사용합니다. 원문을 다시 인식하거나 수정하지 않습니다. 기존 대화록의 오인식이나 대략적인 시간 정보는 UI 변경만으로 교정되지 않습니다.

STT에 극단적인 반복 오류가 생기면 현재 미확정 구간만 한 번 재시도합니다. 해결되지 않으면 확인 표시를 남기고 다음 구간의 녹음을 계속하며 원본 음성과 복구 조각을 보존합니다.

## 프로젝트 구성

```text
Sources/       앱, 오디오 처리, 데이터 모델, MCP 서버, 회귀 검사
Resources/     앱 설정, 권한 설명, 배포용 라이선스 고지
scripts/       명령어 설치, 빌드, 고정 서명, 배포 ZIP 생성·검증, MCP 검사
docs/          설치 안내와 개발자 가이드
releases/      커밋에 포함한 배포 ZIP, 설치 안내, SHA-256
experiments/   앱 실행과 분리한 과거 ASR 비교 실험
```

`Recordings/`, `.runtime/`, `.build/`, `dist/`는 Git에서 제외합니다. 녹음, 모델 가중치, 개인 서명 설정·키를 배포본에 넣지 않습니다.
