FluidAudio 0.17.7
Copyright FluidInference contributors. Apache License 2.0.
https://github.com/FluidInference/FluidAudio/tree/v0.17.7
The full SDK license is included in FluidAudio-LICENSE.txt.

Speaker models are downloaded separately from the FluidInference distribution:
https://huggingface.co/FluidInference/speaker-diarization-coreml
The offline pipeline derives from pyannote Community-1, WeSpeaker and VBx.
Original model attribution and terms:
https://huggingface.co/pyannote/speaker-diarization-community-1 (CC BY 4.0)
https://github.com/wenet-e2e/wespeaker (Apache 2.0)
https://github.com/BUTSpeechFIT/VBx (Apache 2.0)

Live speech activity detection uses Silero VAD (MIT), converted to Core ML by
FluidInference and downloaded separately (silero-vad-unified-256ms-v6.2.1).
https://github.com/snakers4/silero-vad
https://huggingface.co/FluidInference/silero-vad-coreml
FluidAudio's synthesis and speech recognition models are not used.

Optional microphone fan suppression uses LocalVQE v1.3 from localai-org,
converted to Core ML by FluidInference (Apache License 2.0). The four fixed
model files are downloaded separately. The full Apache license is included
in FluidAudio-LICENSE.txt.
https://github.com/localai-org/LocalVQE
https://huggingface.co/FluidInference/localvqe-coreml/tree/4205430781c240397073d6f7bf676fb4c732fc12

WhisperKit (Argmax Open-Source SDK) 1.1.1
Copyright Argmax, Inc. MIT License.
https://github.com/argmaxinc/argmax-oss-swift/tree/v1.1.1
The full SDK license is included in WhisperKit-LICENSE.txt.

The Core ML backends run multilingual OpenAI Whisper models converted by
Argmax. Model and tokenizer files are downloaded separately.
https://huggingface.co/argmaxinc/whisperkit-coreml/tree/main/openai_whisper-large-v3_947MB
https://huggingface.co/argmaxinc/whisperkit-coreml/tree/main/openai_whisper-large-v3-v20240930_626MB
https://github.com/openai/whisper (MIT License)
No audio is sent to a speech recognition API.

whisper.cpp / ggml v1.9.2 (MIT), Copyright (c) 2023-2026 The ggml authors.
The app statically links arm64 Metal code built from the pinned upstream
release source. Its full license is included in whisper.cpp-LICENSE.txt.
https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.2
The Metal backend downloads the OpenAI Whisper large-v3 FP16 weights converted
to GGML separately. No speech is transmitted to the model host.
https://huggingface.co/ggerganov/whisper.cpp/blob/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-large-v3.bin
https://github.com/openai/whisper (MIT License)
