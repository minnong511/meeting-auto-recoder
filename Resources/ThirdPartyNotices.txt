FluidAudio 0.17.7
Copyright FluidInference contributors. Apache License 2.0.
https://github.com/FluidInference/FluidAudio/tree/v0.17.7
The full SDK license is included in FluidAudio-LICENSE.txt.

Speaker models are downloaded separately from the FluidInference distribution:
https://huggingface.co/FluidInference/speaker-diarization-coreml
The offline pipeline derives from pyannote Community-1, WeSpeaker and VBx.
Original model attribution and terms:
https://huggingface.co/pyannote/speaker-diarization-community-1 (CC BY 4.0)
https://github.com/wenet-e2e/wespeaker (Apache 2.0)
https://github.com/BUTSpeechFIT/VBx (Apache 2.0)

Only speaker diarization models are loaded by Meeting Recorder. SDK text-to-speech
and speech recognition models are not downloaded or used by this application.

WhisperKit (Argmax Open-Source SDK) 1.1.1
Copyright Argmax, Inc. MIT License.
https://github.com/argmaxinc/argmax-oss-swift/tree/v1.1.1
The full SDK license is included in WhisperKit-LICENSE.txt.

Live speech recognition uses OpenAI Whisper large-v3-turbo, compressed to 4-bit by
Argmax. Model assets and tokenizer files are downloaded separately and cached.
https://huggingface.co/argmaxinc/whisperkit-coreml/tree/main/openai_whisper-large-v3-v20240930_626MB
https://github.com/openai/whisper (MIT License)
No audio is sent to a speech recognition API.

Final speech recognition can run a separate local MLX worker.
Qwen runtime: MLX Audio 0.6.2 (MIT): https://github.com/Blaizzy/mlx-audio
Cohere runtime: MLX Speech 0.5.4 (MIT): https://github.com/AppAutomaton/mlx-speech
MLX 0.32.4: https://github.com/ml-explore/mlx (MIT).
The selected model and exact revision are recorded in ASRSelection.json.
Qwen3-ASR: https://github.com/QwenLM/Qwen3-ASR (Apache License 2.0).
Cohere Transcribe: https://huggingface.co/CohereLabs/cohere-transcribe-03-2026
(license metadata: Apache License 2.0).
Cohere MLX conversion: https://huggingface.co/appautomaton/cohere-asr-mlx
(license metadata: Apache License 2.0).
Worker dependencies and model weights are installed separately by the local setup
script. Installed Python packages retain their own license metadata. The worker
sets offline mode; it does not upload recordings to a transcription API.
